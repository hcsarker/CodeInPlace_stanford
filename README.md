# Code In Place - Stanford 2025 Batch

This repository contains all the coding exercises, projects, and assignments I have completed as part of the **Code In Place** program by Stanford University, batch of 2025.

## About Code In Place

**Code In Place** is a global introductory programming course designed and taught by Stanford University.  
It aims to provide quality programming education to students worldwide, especially those who may not have easy access to computer science resources.

As a proud student of the 2025 batch, I am maintaining this repository to showcase my learning journey, practice code, and project submissions throughout the course.

## Contents

- Programming exercises and solutions in various languages
- Projects and mini-applications developed during the course
- Notes and resources related to the curriculum
- Collaborative assignments with fellow batchmates

## How to Use This Repository

You can explore each folder to find exercises and projects. Feel free to use the code for learning and personal practice.
